# Security reports

This repository is private. Report sensitive issues through an established private channel with the owner. Do not attach real study data, credentials, window titles or an exploit to a routine issue. Supply a minimal fictional reproduction, affected version/Windows build and impact. No supported-version or response-time guarantee is offered yet.

Records/backups are local and unencrypted by the application. Production disables inspection/Node execution switches and validates ASAR; unsigned binaries can still be replaced by an administrator. QA builds require marked isolated profiles and must never be distributed.

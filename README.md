# FocusRecall

A local-first Windows workspace for focused study, recall notes and personal study records.

**Pre-release · Windows x64 · GPL-3.0-only · No required account**

This repository is private. **Public release and the friend-testing package remain on hold** pending artwork provenance and final release checks. The current controlled candidate is **0.1.0-beta.28-rc.2**. No installer is uploaded by this repository update; existing older draft assets are not the current candidate.

## Study and review

Choose Flow, Fixed or Adaptive timing, use compact floating panels, recall what you can, log optional ratings and take a break. Keep subjects/history/notes locally. Stats helps inspect recorded time and self-ratings with evidence limits; it does not prove learning, causation, mastery or method superiority. Learn offers research-informed explanations and 24 canonical strategies separately from personal observations.

26 approved themes, independent light/dark preferences, keyboard navigation and seven languages include Arabic RTL. Foreground monitoring is **off by default**; title collection is a separate opt-in. Locked/asleep/unobserved time is not automatically credited.

## Installation and testing

Use only an explicitly supplied controlled-test installer and exact checksum. The initial public installer will be unsigned. Back up in Settings, finish studying and quit the tray before an update; retain the existing scope/destination. Stop on data-opening errors and preserve originals/backups. Never reset AppData or disable Windows protections to make a test pass.

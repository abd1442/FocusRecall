# Help, feedback and optional support

## Find an answer

Start with the [main page](README.md) and the detailed [user guide](docs/USER_GUIDE.md), which includes [troubleshooting](docs/USER_GUIDE.md#if-something-goes-wrong). For downloads and platform limitations, use the [Beta 1 release page](https://github.com/abd1442/A14-Pomodoro/releases/tag/v0.1.1-beta.1). Older internal drafts are not the public beta.

## Report a problem

For a routine bug, include:

- A14 Pomodoro version and operating system/version, including Linux desktop/session type or Mac architecture when relevant.
- What you tried, what you expected and what happened.
- The exact error message and whether it happened on first launch, during study or after an update.
- A small fictional reproduction and, if useful, a screenshot checked for private information.

Never attach a personal database, backup, vault, credentials or foreground-window-title history to an issue. Crop unrelated personal windows out of screenshots. If data cannot safely open, preserve originals/backups and stop rather than resetting the profile.

Use the [beta feedback form](https://github.com/abd1442/A14-Pomodoro/issues/new?template=beta-test.yml) for non-sensitive reports; GitHub sign-in is required. Issues are public. Security and sensitive data concerns belong in a private channel: [security reporting](SECURITY.md).

## Show your appreciation

If A14 Pomodoro has been useful to you, you can [show your appreciation on Ko-fi](https://ko-fi.com/abd442). It’s entirely optional. Thank you for using the app. Ko-fi is an external service with its own terms and privacy policy.

You can also help with a clear bug report, careful fictional-profile testing or language feedback. If you test a workflow or translation, tell us which Windows version and language you used.

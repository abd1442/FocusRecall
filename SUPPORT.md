# Help, feedback and optional support

## Find an answer

Start with the [main page](README.md) and the detailed [user guide](docs/USER_GUIDE.md), which includes [troubleshooting](docs/USER_GUIDE.md#if-something-goes-wrong). For installer availability and controlled testing, see [release status](docs/RELEASE_STATUS.md). No public installer is currently offered, and older draft assets should not be used as the latest download.

## Report a problem

For a routine bug, include:

- FocusRecall version and Windows edition/build (Windows Settings → System → About).
- What you tried, what you expected and what happened.
- The exact error message and whether it happened on first launch, during study or after an update.
- A small fictional reproduction and, if useful, a screenshot checked for private information.

Never attach a personal database, backup, vault, credentials or foreground-window-title history to an issue. Crop unrelated personal windows out of screenshots. If data cannot safely open, preserve originals/backups and stop rather than resetting the profile.

Use the repository issue form for non-sensitive reports if you have access, or the private channel agreed for your controlled test. Security and sensitive data concerns belong in a private channel: [security reporting](SECURITY.md).

## Show your appreciation

If FocusRecall has been useful to you, you can [show your appreciation on Ko-fi](https://ko-fi.com/abd442). It’s entirely optional. Thank you for using the app. Ko-fi is an external service with its own terms and privacy policy.

You can also help with a clear bug report, careful fictional-profile testing or language feedback. If you test a workflow or translation, tell us which Windows version and language you used.

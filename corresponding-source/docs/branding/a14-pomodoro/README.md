# A14 Pomodoro branding

Approved by the owner on 30 October 2026: **Countdown Corner**, option 1 from the simple badge directions. The badge carries A14; the wordmark reads Pomodoro. The accessible and textual product name is **A14 Pomodoro**.

- Navy: `#233957`
- Gold: `#F0B35B`
- White: `#FFFFFF`
- Lettering: Bahnschrift SemiBold, converted to editable vector outlines. No font software is bundled. The application's established body typography remains unchanged.

Production assets are `resources/a14-pomodoro-icon.svg`, `a14-pomodoro-icon.png`, `a14-pomodoro.ico`, `a14-pomodoro-lockup.svg` and `a14-pomodoro-lockup-dark.svg`. The PNG master is 1024 × 1024. ICO exports contain nine sizes from 16 to 256 pixels. Source vectors use original badge geometry and outlined lettering, not the previous F/R artwork or the supplied Coach image. The Coach image informed the badge-and-name layout only.

The sidebar uses the approved outline artwork with theme-aware foreground/background colors and the unchanged gold accent. The compact rail uses the badge alone. The idle tray uses the badge; active stage colors retain their existing timer meaning.

Previous concepts are retained here as design records. They are not packaged with the application. Old product names remain only where required for compatibility, immutable earlier releases or clearly identified historical evidence. No trademark clearance claim is made.
